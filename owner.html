کنسول مالک سایت

ورود امن به مدیریت سراسری هم‌تماشا. این مسیر در هیچ منویی لینک نشده است.

ورود ساده و مستقیم ورود فقط با رمز ثابت مالک انجام می‌شود. اتصال گیت‌هاب و توکن PAT به‌طور کامل غیرفعال شده است و برای ورود هیچ حساب دیگری لازم نیست. نشست مالک تا بسته‌شدن تب فعال می‌ماند.

رمز مالک را وارد کن؛ اتصال گیت‌هاب لازم نیست.

چطور توکن امن بسازم؟
  1. وارد GitHub شو → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. در Repository access گزینهٔ Only select repositories را بزن و مخزن sepehr007/sepehr007.github.io را انتخاب کن.
  3. در Repository permissions فقط Contents را روی Read and write بگذار. Metadata خودکار Read-only است.
  4. Expiration را کوتاه بگذار (مثلاً ۹۰ روز)، توکن را کپی کن و فقط در همین کادر بچسبان.
  5. توکن را در چت، Issue، اسکرین‌شات یا کد نگذار. این صفحه آن را فقط در حافظهٔ همین تب نگه می‌دارد.

فعالیت اخیر

مرزهای صادقانهٔ معماری

سایت روی GitHub Pages استاتیک اجرا می‌شود. این کنسول تنظیمات سایت را از طریق API گیت‌هاب در مخزن شما منتشر می‌کند و همان تنظیمات واقعاً روی همهٔ بازدیدکنندگان اعمال می‌شود. اما فهرست اتاق‌های زنده، آمار سراسری بازدید، مسدودسازی کاربران در همهٔ دستگاه‌ها و کنترل IP بدون بک‌اند ممکن نیست؛ موارد این صفحه که «محلی» برچسب خورده‌اند فقط روی همین مرورگر اثر دارند.

هویت و برند

نام و شعار در سربرگ، عنوان صفحه و توضیحات متا استفاده می‌شود.

رنگ‌ها فقط برای بازدیدکنندگانی اعمال می‌شود که هنوز ظاهر شخصی انتخاب نکرده‌اند؛ انتخاب کاربر همیشه اولویت دارد.

اطلاعیهٔ سراسری

پیش‌نمایش اطلاعیه

حالت تعمیرات

با روشن‌بودن این گزینه، صفحات سایت یک لایهٔ تمام‌صفحه نشان می‌دهند. خود مالک در همین مرورگر آزاد است.

دسترسی عمومی

این کلیدها رابط کاربری همهٔ صفحات را کنترل می‌کنند. چون سایت استاتیک است، دور زدن با ابزار توسعه‌دهنده ممکن است؛ برای کنترل واقعی هویت به بک‌اند نیاز است.

مرکز کنترل قابلیت‌ها

خاموش‌کردن هر مورد، دکمه/پنل مربوط را در اتاق پنهان و مسیر آن را می‌بندد.

ظرفیت و نرخ مجاز

این اعداد در ساخت اتاق و محدودکننده‌های چت/آواتار/اکشن اعمال می‌شوند. محدودیت واقعی IP همچنان به بک‌اند نیاز دارد.

پلن پریمیوم

بدون درگاه و بک‌اند، فعال‌سازی خودکار اشتراک ممکن نیست. می‌توانی یک لینک پرداخت میزبانی‌شده (مثل Stripe Payment Link) بگذاری؛ دکمهٔ خرید همان لینک واقعی را باز می‌کند.

اگر لینک خالی باشد، دکمه غیرفعال می‌ماند و موفقیت جعلی نمایش داده نمی‌شود.

حساب‌های همین مرورگر

این حساب‌ها در localStorage همین مرورگر هستند. مسدودکردن یا حذف، فقط روی همین دستگاه اثر قطعی دارد؛ ادعای مسدودسازی سراسری نمی‌کنیم.

رمز ثابت مالک

ورود این نسخه فقط با رمز ثابت مالک انجام می‌شود و رمز داخل مرورگر با PBKDF2 بررسی می‌شود. تغییر رمز از این صفحه غیرفعال است.

اتصال به بک‌اند

برای اتصال واقعی به سرویس، مقدار apiBase را در فایل assets/data/runtime-config.json تنظیم کن (مثلاً https://api.example.com/api). تا وقتی این مقدار خالی باشد، سایت در حالت محلی کار می‌کند و هیچ داده‌ای به سرور نمی‌فرستد.

آمار مصرف

بدون بک‌اند و پایگاه داده، آمار سراسری بازدید، اتاق و پیام وجود ندارد. این بخش ساختار پایه برای اتصال به API آمار در فاز بعد است و عدد ساختگی نمایش نمی‌دهد.
