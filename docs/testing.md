# تست و تضمین کیفیت

دو مجموعهٔ تست خودکار در `server/tests/` هست. هر دو روی SQLite موقت داخل `server/.tmp` اجرا می‌شوند و به دادهٔ واقعی یا سرویس بیرونی دست نمی‌زنند.

```bash
cd server
npm test             # هر دو مجموعه
npm run test:sec     # امنیت و realtime (۳۸)
npm run test:qa      # بخش ۴۲: حساب، اتاق، رسانه، کسب‌وکار، پلتفرم
npm run release:check # بررسی انتشار (۳۷ بررسی)
```

پیش‌نیاز: Node ≥ 22.5. تست‌ها سرور Fastify را روی پورت تصادفی بالا می‌آورند و با `fetch`/WebSocket واقعی آزمایش می‌کنند.

## تست مرورگر واقعی

با Chrome headless روی CDP و API محلی، ۹ صفحه (لندینگ، ورود/ثبت‌نام، پروفایل، اتاق‌ها، اجتماعی، اتاق، صفحهٔ سازنده، کنسول مالک، آفلاین) در سه اندازهٔ دسکتاپ، تبلت و موبایل بررسی شدند: **۲۷ ترکیب** بدون خطای کنسول، استثنای جاوااسکریپت، درخواست هم‌مبدأ ناموفق یا سرریز افقی.

ثبت‌نام کامل در ۳۹۰×۸۴۴ هم با رابط واقعی انجام شد: کپچا → تأیید ایمیل → کد بازیابی → لابی؛ توکن و کاربر در مرورگر ماندند و پروفایل/اتاق‌ها/اجتماعی با هدر واردشده درست رندر شدند.

در همین بررسی یک ایراد واقعی چیدمان هدر لندینگ زیر ۵۶۰ پیکسل پیدا و رفع شد (شکستن برچسب دکمه‌ها در دو ردیف). پس از اصلاح، ماتریس دوباره اجرا شد و بدون ایراد بود؛ نسخهٔ کش سرویس‌ورکر برای تحویل همان تغییر بالا رفت.

جریان امنیتی مالک روی مرورگر واقعی هم اجرا شد: ورود با حساب مالک سرور، نمایش ایمیل/شمارهٔ ماسک‌شده، دریافت کد آزمایشی (ایمیل یا پیامک) از outbox، تغییر رمز از خود کنسول با همان یک کد، رد شدن رمز قبلی و پذیرش رمز جدید — بدون خطای کنسول و بدون سرریز افقی. برای حساب مالک، کارت «امنیت حساب» در پروفایل عادی فقط پیام راهنما نشان می‌دهد و فرم تغییر رمز حذف می‌شود؛ همین محدودیت در API هم اعمال شد.

تست خودکار مرورگر در مخزن نیست چون به ابزار مرورگر بیرونی نیاز دارد؛ اسکریپت‌های موقت در `server/.tmp` (خارج از گیت) بودند.

## مواردی که در این محیط قابل تست نیست

- **درگاه پرداخت واقعی:** هیچ قرارداد پذیرندگی وصل نیست؛ مسیر `manual` (واریز + تأیید مالک) تست شد. وبهوک HMAC بدون راز واقعی درگاه قابل آزمون نیست.
- **SMTP/پیامک واقعی:** ایمیل و پیامک در حالت outbox ذخیره می‌شوند؛ تحویل واقعی نیاز به اعتبارنامه دارد.
- **WebRTC صدا و اشتراک صفحه بین دو دستگاه:** فقط مسیرهای سیگنالینگ/اتاق تست‌شده‌اند؛ کیفیت رسانه و TURN واقعی در این محیط سنجیده نشد.
- **Mongo/Redis:** در این محیط نصب نیستند؛ کد مسیر SQLite تست شده و مسیرهای Mongo/Redis فقط از نظر پیکربندی بررسی شده‌اند.
- **کیبورد نرم واقعی اندروید/iOS:** منطق `visualViewport` و فوکوس با ورودی شبیه‌سازی‌شده بررسی شده، نه روی دستگاه فیزیکی.
