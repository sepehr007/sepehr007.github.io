# امنیت و حریم خصوصی هم‌تماشا

گزارش ممیزی واقعی بخش ۳۸: هر یافته با محل، اصلاح و وضعیت تست. چیزی که در این نصب قابل اثبات نبوده، ادعا نشده است.

## خلاصه

- احراز هویت WebSocket و فایل‌های خصوصی قبلاً فقط «امضای توکن» را می‌دید؛ حالا نشست، وجود حساب و وضعیت آن را هم بررسی می‌کند.
- کاربر تعلیق‌شده/حذف‌شده دیگر نمی‌تواند با توکن قدیمی کار کند؛ تغییر نقش یا وضعیت همهٔ نشست‌ها را باطل می‌کند.
- ورود با قفل حساب (۱۰ تلاش ناموفق / ۱۵ دقیقه) و سقف دعوت (۵۰ دعوت فعال و ۳۰ ساخت در ۲۴ ساعت) محافظت می‌شود.
- هر اقدام مدیریتی/اتاقی در `moderation_actions` ثبت می‌شود، نه فقط در لاگ متنی.
- هدرهای امنیتی روی همهٔ پاسخ‌های API اضافه شد (nosniff، deny framing، referrer، permissions، COOP، HSTS در استقرار، no-store).
- هاب WebSocket اعتبارسنجی رویداد، ضدتکرار (`cid`)، شمارهٔ ترتیب (`seq`) و بافر ادامهٔ اتصال، heartbeat، سقف فریم و محدودیت سیلان دارد.

## چیزهایی که از قبل درست بود (تأیید شده)

- کوکی ندارد؛ JWT با هدر Bearer → سطح CSRF کلاسیک صفر است.
- کوئری‌ها همه prepared؛ ورودی‌های متنی `cleanText`/`slice` می‌شوند.
- آپلود: فهرست نوع مجاز + magic-byte + سهمیه + `path.resolve`؛ مسیر خروج از سبد رد می‌شود.
- وب‌هوک پرداخت: HMAC + `UNIQUE(provider,event_id)` + تطبیق مبلغ؛ رازها فقط env.
- پیام خصوصی فقط برای دو طرف مکالمه (`conversationFor`) خوانده می‌شود؛ در API عمومی نیست.
- صفحه‌های سازنده فقط بلوک ازپیش‌تعریف‌شده با پاک‌سازی لینک/تصویر؛ HTML دلخواه اجرا نمی‌شود.
- آمار نظرسنجی خام است و رأی سایر کاربران را لو نمی‌دهد.

## ریسک‌های باقی‌مانده (صادقانه)

1. **سیگنالینگ ntfy.sh:** WebRTC هنوز از رلهٔ عمومی با موضوع مشتق از کد اتاق استفاده می‌کند. محتوا رمزنگاری‌شده است اما متادیتا و کد اتاق نزد شخص ثالث است. مهاجرت به سیگنالینگ سرور، تغییر `net.js` و تست دو مرورگر واقعی می‌خواهد.
2. **JWT در localStorage:** CSRF نداریم ولی XSS = سرقت توکن. کاهش ریسک با CSP سخت‌گیرانه روی GitHub Pages ممکن است ولی با اینلاین‌های فعلی ریسک شکستن دارد؛ انجام نشد.
3. **بدون Pub/Sub:** با چند نمونه سرور، `notifyUser`/`notifyRoom` بین نمونه‌ها پخش نمی‌شود؛ روی یک نمونه کامل است.
4. **CSP کامل ارائه نمی‌شود:** API هدرهای امنیتی دارد؛ صفحه‌های استاتیک GitHub Pages از کنترل سرور خارج‌اند.
5. **نرخ مبتنی بر حافظه بدون Redis:** در حالت بدون Redis شمارنده‌ها هر نمونه جدا هستند و با ری‌استارت صفر می‌شوند (نشست‌ها دوام دارند).
6. **آواتار/تصاویر از URL خارجی** در پروفایل مجاز است؛ SSRF سمت سرور نیست (سرور آن را دانلود نمی‌کند) ولی محتوای شخص ثالث است.
7. **بازگردانی رمز** از طریق کد و ایمیل/پیامک انجام می‌شود؛ در نصب محلی بدون SMTP فقط در outbox ثبت می‌شود.
