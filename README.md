# هم‌تماشا — Watch Together

پلتفرم تماشای هم‌زمان فیلم با چت و صدای زنده، کاملاً داخل مرورگر و بدون سرور.

## چطور اجرا می‌شود

### آنلاین (GitHub Pages)
آدرس سایت: **https://sepehr007.github.io**

### روی سیستم خودت
پوشه پروژه را باز کن و یک سرور ساده اجرا کن:

```bash
cd D:\Site
python -m http.server 8000
```
سپس در کروم برو به: `http://localhost:8000`

> افتتاح فایل با دوبار کلیک (`file://`) کار نمی‌کند، چون WebRTC و ماژول‌های جاوااسکریپت به `http` یا `https` نیاز دارند.

## چطور کار می‌کند
- هر اتاق یک کد ۶ حرفی دارد. سازنده اتاق، «میزبان» است.
- میزبان مرورگرش نقش سرور را بازی می‌کند: وضعیت پخش، اعضا، چت و صف را نگه می‌دارد.
- بقیه با WebRTC مستقیم به میزبان وصل می‌شوند. فقط «دست‌دادن» اولیه (سیگنالینگ) از سرویس عمومی و رایگان ntfy.sh رد می‌شود — هیچ دیتابیس یا سروری در کار نیست.
- صدای زنده به صورت mesh بین اعضا برقرار می‌شود.

## امکانات پیاده‌شده
- ساخت/ورود به اتاق با لینک یا کد، اتاق عمومی و رمزدار، ظرفیت، قفل اتاق
- نقش‌ها: میزبان، مدیر، عضو + اخراج، مسدودسازی، بی‌صدا کردن، ارتقا/تنزل
- پخش همگام: پخش/توقف/جابه‌جایی، ±۵ و ±۱۰ ثانیه، سرعت، تصحیح خودکار اختلاف زمانی، همگام‌سازی تازه‌واردها
- MP4 و HLS (m3u8) با hls.js
- تمام‌صفحه، حالت تئاتر، PiP، ذخیره محل توقف
- چت: ری‌اکشن، پاسخ، ویرایش، حذف، سنجاق، منشن، تایپینگ، جستجو، تاریخچه
- صدای زنده: میکروفون، قطع صدا، ناشنوایی، نشانگر صحبت، ولوم هر نفر
- زیرنویس SRT/VTT با تغییر اندازه و تأخیر
- صف پخش با رأی‌گیری
- دو زبانه فارسی (RTL) و انگلیسی (LTR)
- PWA، طراحی موبایل تا مانیتور بزرگ

## محدودیت‌های صادقانه
- **بدون حساب کاربری**: هویت با نام نمایشی است و رمز عبور واقعی وجود ندارد (درخواست «بدون ثبت‌نام»). امنیت اتاق‌ها بر پایه لینک/رمز اتاق است.
- **میزبان باید صفحه را باز نگه دارد**؛ بستن مرورگر میزبان یعنی بسته‌شدن اتاق.
- **صدای گروهی** برای اتاق‌های کوچک (تا حدود ۶ نفر) بهینه است؛ mesh است.
- **پنل مدیریت سایت / صفحه‌ساز بدون کد** پیاده نشده — بدون بک‌اند و دیتابیس ممکن نیست.
- لینک ویدیو باید مستقیم (`https`) باشد؛ YouTube/Netflix پشتیبانی نمی‌شوند.
- پخش خودکار ممکن است در بعضی مرورگرها تا اولین کلیک مسدود بماند.

## ساختار فایل‌ها
```
index.html              صفحه اول (ساخت/ورود)
room.html               صفحه اتاق
assets/css/style.css    استایل کامل
assets/js/core.js       ابزارها، اعتبارسنجی لینک، Toast
assets/js/i18n.js       مترجم فا/EN
assets/js/net.js        لایه اتاق (ntfy signaling + WebRTC)
assets/js/player.js     پلیر و همگام‌سازی + زیرنویس
assets/js/voice.js      صدای زنده
assets/js/room.js       رابط اتاق
assets/js/landing.js    رابط صفحه اول
sw.js / manifest.webmanifest   PWA
```
